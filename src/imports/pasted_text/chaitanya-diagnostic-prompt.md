# SEO REQUIREMENTS

This is extremely important.

Build the website with proper SEO structure.

Implement:

* Unique title for every page
* Unique meta description
* Semantic HTML
* H1/H2/H3 hierarchy
* SEO-friendly URLs
* Open Graph metadata
* Twitter metadata
* Canonical URLs
* Image alt text
* Descriptive image filenames
* Internal linking
* Breadcrumbs
* FAQ schema
* LocalBusiness schema
* MedicalBusiness / appropriate healthcare structured data where appropriate
* Organization schema
* Service schema
* Article schema for health articles
* Sitemap-ready architecture
* Robots.txt-ready structure
